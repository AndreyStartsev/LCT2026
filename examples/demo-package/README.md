# Демонстрационный пакет «НК12-2023»

Готовый объект для первого знакомства с сервисом: 7 PDF, 21 страница, 0,8 МБ. У всех страниц
есть текстовый слой, поэтому разбор идёт за секунды и не зовёт ни распознавание, ни модель.
Объект, организации, люди и реквизиты вымышлены. Нарушения заложены в двух местах, остальное
по стадиям совпадает.

## Как загрузить

**В браузере.** Экран загрузки → выбрать папку `НК12-2023` целиком. Стадию сервис определит
по вложенным папкам `01_ПД`, `02_РД`, `03_ИД`. Подходит любой способ чтения, быстрее всего —
«только слой».

**Загрузчиком:**

```bash
python3 tools/upload_object.py --folder examples/demo-package/НК12-2023 --object-id DEMO-NK12
```

## Что сервис должен найти

Экран верификации → «Протокол» → таблица **2 «Кандидаты в нарушения»**, две записи.
Инспектор ничего не отмечает заранее: обе записи сервис находит сам.

### 1. KR-055 — класс бетона фундаментной плиты понижен: B30 → B25

Проект задаёт B30 W8 F150. Рабочая документация снизила класс до В25. Исполнительная
подтверждает, что плиту построили из В25. На карточке: ПД B30, РД B25, ИД B25,
«ИД против рабочей стадии: значения совпадают». Критичность — «Критическое (приостановка работ)».

| Стадия | Где | Что на странице |
|---|---|---|
| ПД | НК12-2023-КР, стр. 3 (лист 2) | «Фундаментная плита — … из бетона класса B30 W8 F150» |
| ПД | НК12-2023-КР, стр. 5 (лист 4) | таблица 4.10: «Фундаментная плита 800 мм — B30» |
| ПД | НК12-2023-КР, стр. 6 (лист 5) | схема фундаментной плиты, примечание 1 |
| РД | НК12-2023-КЖ1, стр. 1 (лист 1) | общие указания, п. 3: «… из бетона класса В25 W8 F150» |
| РД | НК12-2023-КЖ1, стр. 2 (лист 2) | опалубочный план, примечание 1 |
| ИД | Протокол № 218-Б, стр. 1 | три строки «Фундаментная плита Фм-1 … B25 … %» |
| ИД | АООК № 001, стр. 1 | п. 3: «смесь бетонная … БСТ В25 П4 F150 W8» |

### 2. IOS4-078 — в помещении 107 нет вытяжной вентиляции

По проекту санузел 107 обслуживает система В9. В рабочей документации В9 обслуживает только
104 и 105, а помещения 107 в таблице систем нет. На плане 107 есть, но без решётки и без
марки. Нарушение сравнивает лист ПД с чертежом РД по номеру помещения. На карточке стоит
отметка «требует подтверждения»: сравнение по помещениям без подтверждения инспектора
нарушением не становится.

| Стадия | Где | Что на странице |
|---|---|---|
| ПД | НК12-2023-ИОС4, стр. 3 (лист 2) | строка «В9 · 1 · Санузлы пом. 104, 105, 107», рамка на строке |
| ПД | НК12-2023-ИОС4, стр. 4 (лист 3) | план: помещение 107 с маркой В9, рамка на номере |
| РД | НК12-2023-ОВ, стр. 2 (лист 2) | таблица систем: у В9 только 104, 105 |
| РД | НК12-2023-ОВ, стр. 3 (лист 3) | план: помещение 107 без вытяжки, рамка на номере |

### Остальное — «нарушения нет»

Таблица **4 «Проверенные отрицательные»**, 16 записей. Среди них:

- классы бетона стен, плит перекрытий и лестниц по частям здания (KR-055);
- класс арматуры (KR-057);
- толщина фундаментной плиты по всем трём стадиям (KR-058);
- толщина плит перекрытия (KR-059) и толщина стен (KR-061);
- абсолютная отметка нуля (PZ-009);
- состав систем остальных помещений (IOS4-078).

В таблице 1 «Комплектность и сопоставимость» и в таблице 5 «Гипотезы» записей нет.

## Проверка

```bash
python3 tests/test_demo_package.py
```

Тест проводит пакет сквозным прогоном во временный каталог и проверяет стадии, основную надпись,
чтение одним слоем и ровно два нарушения с доказательствами.
