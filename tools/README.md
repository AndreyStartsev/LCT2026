# Вспомогательные скрипты

| Скрипт | Назначение |
|---|---|
| `upload_object.py` | провести папку объекта через сервис: загрузка без лимитов размера под учётной записью `admin`, ожидание и сохранение протокола |
| `fix_filenames.py` | восстановить имена файлов, пришедшие в кодировке cp866 |

## Загрузчик папки объекта

```bash
python3 tools/upload_object.py --folder "/путь/к/объекту" --object-id OBJ-1 --object-name "Название объекта"
```

Загрузчик создаёт объект, раскладывает файлы по стадиям, дожидается протокола и сохраняет его
в `protocol-<объект>.json` (другое место — ключ `--out`). Под учётной записью `admin` файлы
любого размера принимаются маршрутом без лимитов; под другой ролью действуют лимиты браузера.
Другой адрес сервиса — ключ `--api`, другая учётная запись — `--login` и `--password`.

## Восстановление имён файлов

Корпус документов иногда приходит с именами в кодировке cp866, прочитанными как cp1251 или cp1252.
Скрипт подбирает исходную кодировку для каждого имени и переименовывает файлы.

```bash
python3 tools/fix_filenames.py --root "/путь/к/объекту"
python3 tools/fix_filenames.py --root "/путь/к/объекту" --apply --map rename_map.json
```

Без `--apply` скрипт только показывает план. Карта отката пишется в файл из `--map` и позволяет
вернуть всё обратно. Имена без признаков порчи — чистая кириллица и латиница — не трогаются.
Файлы сопоставляются по SHA-256 содержимого, поэтому переименование на результат сверки не влияет.
