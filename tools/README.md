## Восстановление имён файлов

Корпус приходит с именами в кодировке cp866, прочитанными как cp1251 или cp1252.
Скрипт подбирает исходную кодировку по каждому имени и переименовывает.

```bash
python tools/fix_filenames.py --root data/17_Изумрудная_12
```

```bash
python tools/fix_filenames.py --root data/17_Изумрудная_12 --apply --map tools/rename_map_izumrudnaya.json
```

Без `--apply` только показывает план. Карта отката пишется рядом и позволяет вернуть
всё обратно.

**Трогаются только имена с явными признаками порчи.** Чистая кириллица и латиница
не затрагиваются. Это важно: попытка «улучшить» уже правильное имя однажды превратила
`18_Октябрьская_103` в нечитаемое, и пришлось откатывать по карте.

**Имена в корпусе не переименовываем без нужды.** Манифест организатора ссылается
на исходные пути, а сопоставление файлов у нас идёт по SHA-256 содержимого.
Восстановление имён нужно людям, а не коду.
